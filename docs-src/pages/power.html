Power series and uniform convergence

powerSeries(c) is \(\sum c_n (x - a)^n\) for a formula \(c_n\). It finds the radius of convergence, examines each end of the interval, and evaluates the series with a proven tail. taylorRemainder puts Lagrange's bound beside the true error, and functionSequence measures the distance between a sequence of functions and its limit.

const p = powerSeries("1/n", { from: 1 });      // x + x^2/2 + x^3/3 + …  = -log(1 - x)
p.radius();          // { radius: 1, limit: 1, by: "ratio" }
p.interval().text;   // "[-1, 1)"
p.interval().left;   // { point: -1, convergence: "conditionally convergent", by: "alternating", … }
p.interval().right;  // { point: 1,  convergence: "divergent", by: "comparison", … }

powerSeries("1/n!").interval().text;            // "(-inf, inf)"
powerSeries("n!").interval().text;              // "{0}"
powerSeries("2^n/n^2", { from: 1 }).interval().text;   // "[-1/2, 1/2]"
powerSeries("1/n!").value(1, { digits: 15 }).enclosure;   // e, to 15 digits

Radius and end points

A power series converges absolutely for \(|x - a| < R\) and diverges for \(|x - a| > R\), where

\[ \frac1R = \lim_{n\to\infty}\left|\frac{c_{n+1}}{c_n}\right| \]

when that limit exists. At the two points \(|x - a| = R\) the theorem is silent, and anything can happen: \(\sum x^n/n\) converges at \(-1\) and diverges at \(1\), \(\sum x^n/n^2\) converges at both, \(\sum x^n\) at neither. So when \(R\) is an exact rational number, interval() forms the two numerical series \(\sum c_n(\pm R)^n\) and runs the convergence tests on each. The bracket in text is square where the series is proven to converge, round where it is proven to diverge, and ? where no test decided.

Operations

Inside its interval a power series can be differentiated and integrated term by term, and the radius does not change (the ends may).

const d = p.derivative();      // Σ x^n, the geometric series
d.interval().text;             // "(-1, 1)": both ends are lost
p.integral();                  // Σ x^n/(n(n - 1)) from n = 2
p.partial(4);                  // x + 1/2*x^2 + 1/3*x^3 + 1/4*x^4 as a function, to plot or evaluate
p.at("1/2").sum();             // the numerical series at x = 1/2: encloses log 2

Taylor's remainder against the true error

Taylor's theorem bounds the error of the polynomial \(T_n\) of order \(n\) about \(a\):

\[ |f(x) - T_n(x)| \le \frac{M\,|x-a|^{n+1}}{(n+1)!}, \qquad M \ge \max |f^{(n+1)}| \text{ between } a \text{ and } x . \]

taylorRemainder computes both sides on an interval. \(M\) is the certified range of the next derivative, so the bound is a proven one. The true maximum of \(|f - T_n|\) is enclosed as well, so you can see how much the bound overestimates.

const r = taylorRemainder("exp(x)", { about: 0, order: 4, on: [-1, 1] });
r.M;        // [0.3678…, 2.7182…]: the range of |f⁽⁵⁾| = exp on [-1, 1]
r.bound;    // 0.02265… = e/120
r.actual;   // [0.009948…, 0.009948…]: the true largest error, at x = 1
r.holds;    // true

Pointwise and uniform convergence

A sequence of functions \(f_n\) converges to \(f\) pointwise on a set if \(f_n(x) \to f(x)\) for each \(x\), and uniformly if the largest error goes to zero:

\[ \sup_x |f_n(x) - f(x)| \to 0 . \]

The difference matters: a uniform limit of continuous functions is continuous and can be integrated term by term, and a pointwise limit need not be. The standard example is \(x^n\) on \([0, 1]\), whose pointwise limit jumps at 1.

const f = functionSequence("x^n");
f.pointwise("1/2");                  // 0
f.supDistance(5, [0, "9/10"]);       // [0.59049, 0.59049]: sup |x^5 - 0| on the interval
f.uniform(["1/10", "9/10"]).verdict; // "uniform": a bound for every x at once that tends to 0
f.uniform([0, 1]).verdict;           // "not uniform so far": the supremum is 1 for every n tried

supDistance returns an interval for the supremum: the upper end is a proven bound from a certified range, the lower end a value the difference really takes. uniform returns the table of these for several \(n\), and a verdict. It says "uniform" only with a proof, which is the asymptotic bound of the sequences page carried out with \(x\) standing for the whole interval. When the suprema stay away from 0 it says "not uniform so far", which is evidence about the \(n\) tried and is labelled as that. Otherwise the verdict is "undecided" and the table is what you have.
