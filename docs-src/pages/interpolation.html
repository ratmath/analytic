Numerical methods

Interpolation and approximation

The polynomial through a set of points, in Newton's and Lagrange's forms with exact divided differences; the error formula beside the true error; Chebyshev nodes and the Runge phenomenon; natural cubic splines and least-squares polynomials, all with exact rational coefficients.

const p = interpolate([[0, 1], [1, 3], [2, 2]]);
p.polynomial;            // "-3/2*x^2 + 7/2*x + 1"
p.newton;                // "1 + 2*x - 3/2*x*(x - 1)"
p.dividedDifferences;    // [[1, 3, 2], [2, -1], [-3/2]]   exact
p.at("1/2");             // 19/8

const q = interpolate("sin(x)", { nodes: equallySpaced(0, 1, 4) });
q.maxError([0, 1]);      // { value, attained, at, textbook }

Divided differences

Through \(n + 1\) points with distinct \(x_i\) there is exactly one polynomial of degree at most \(n\). Newton's form builds it one node at a time:

\[ p(x) = f[x_0] + f[x_0, x_1](x - x_0) + f[x_0, x_1, x_2](x - x_0)(x - x_1) + \dots, \qquad f[x_i, \dots, x_{i+k}] = \frac{f[x_{i+1}, \dots, x_{i+k}] - f[x_i, \dots, x_{i+k-1}]}{x_{i+k} - x_i}. \]

The table of divided differences is computed in exact rational arithmetic, so for data given as rationals the polynomial is the true one, with no rounding. Lagrange's form writes the same polynomial as \(\sum y_i\,\ell_i(x)\), where \(\ell_i\) is 1 at \(x_i\) and 0 at the other nodes.

The error formula

If \(f\) has \(n + 1\) continuous derivatives, then for each \(x\) there is a \(\xi\) with

\[ f(x) - p(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}\,\prod_{i=0}^{n}(x - x_i). \]

maxError reports the true maximum of \(|f - p|\) on an interval, bracketed between a value attained and a proven upper bound, and beside it the bound the formula gives, \(\max|f^{(n+1)}| / (n+1)! \cdot \max|\prod (x - x_i)|\), with both maxima enclosed.

Runge's example and Chebyshev nodes

More nodes need not mean a better fit. For \(f(x) = 1/(1 + 25x^2)\) on \([-1, 1]\) with equally spaced nodes the error near the ends grows without bound as the degree rises. The product \(\prod(x - x_i)\) is the part of the error formula that the choice of nodes controls, and it is smallest in maximum when the nodes are the Chebyshev points

\[ x_i = \cos\frac{(2i + 1)\pi}{2n}, \qquad i = 0, \dots, n - 1, \]

which crowd towards the ends. chebyshevNodes(a, b, n) returns them rounded to nearby rationals.

Splines and least squares

A natural cubic spline is a cubic on each interval between nodes, with two continuous derivatives across the nodes and zero second derivative at the two ends. The second derivatives at the nodes solve a tridiagonal system, here exactly. A least-squares polynomial of degree \(d\) minimises \(\sum (p(x_i) - y_i)^2\); its coefficients solve the normal equations \(A^{\mathsf T}A\,c = A^{\mathsf T}y\), again exactly, and the residual is returned as an exact rational.
