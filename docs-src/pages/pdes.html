Heat, waves and potentials

The three classical partial differential equations, solved by separation of variables with certified Fourier coefficients and a proven bound on the part of the series left out; the wave equation by d'Alembert's formula; and the eigenvalue problems behind separation of variables, by shooting.

const rod = heat({ k: 1, length: 1, initial: "x*(1 - x)", terms: 6 });
rod.at("1/2", "1/10");
// { value: [0.0961618714341, 0.0961618714350], partial: […], tail: 4.9e-22 }

const string = wave({ c: 1, length: 1, position: "sin(pi*x)" });
string.at("1/4", "1/3");             // exact up to rounding: d'Alembert's formula

const plate = laplaceRectangle({ top: "x*(1 - x)", terms: 8 });
plate.at("1/2", "3/4");

Which kind of equation

A second-order linear equation \(A u_{xx} + B u_{xy} + C u_{yy} + (\text{lower order}) = 0\) is hyperbolic where \(B^2 - 4AC > 0\), parabolic where it is 0 and elliptic where it is negative, like the conic \(Ax^2 + Bxy + Cy^2\). The wave, heat and Laplace equations are the three model cases. classifyPDE({ A, B, C }) (also pde.classify) computes the discriminant; when \(A\), \(B\), \(C\) depend on \(x\) and \(y\) the type can change from region to region. The Tricomi equation \(y\,u_{xx} + u_{yy} = 0\) has discriminant \(-4y\): hyperbolic for \(y < 0\), parabolic on \(y = 0\), elliptic for \(y > 0\). at(x, y) decides the type at a point (exactly for polynomial coefficients) and on(rectangle) proves a single type on a rectangle or returns null.

The heat equation

For \(u_t = k\,u_{xx}\) on \(0 < x < L\) with both ends held at 0, try \(u = X(x)\,T(t)\). Then \(T'/(kT) = X''/X\), a function of \(t\) equal to a function of \(x\), so both are a constant \(-\lambda\). The boundary conditions force \(X = \sin(n\pi x/L)\) and \(\lambda = (n\pi/L)^2\), and superposing,

\[ u(x, t) = \sum_{n=1}^{\infty} b_n\,e^{-k(n\pi/L)^2 t}\,\sin\frac{n\pi x}{L}, \qquad b_n = \frac{2}{L}\int_0^L f(x)\sin\frac{n\pi x}{L}\,dx . \]

The \(b_n\) are the sine coefficients of the initial temperature, which fourier encloses. With insulated ends (ends: "insulated") the series is in cosines and the temperature tends to its mean.

The tail. Since \(|b_n| \le 2\sup|f|\), and \(e^{-cn^2} \le \rho^n\) for \(n > N\) with \(\rho = e^{-c(N+1)}\), \(c = k\pi^2 t/L^2\),

\[ \Bigl|\sum_{n > N} b_n e^{-cn^2}\sin\frac{n\pi x}{L}\Bigr| \le 2\sup|f| \cdot \frac{\rho^{N+1}}{1 - \rho}. \]

So at(x, t) returns the partial sum as an enclosure, this bound as tail, and their sum value, which contains the true temperature. For any \(t > 0\) the tail is tiny after a few terms: the heat equation smooths. At \(t = 0\) the series is the Fourier series of \(f\), no such bound holds, and value is null.

Laplace's equation

On the rectangle \(0 < x < a\), \(0 < y < b\) with \(u = f(x)\) on the top edge and 0 on the others,

\[ u(x, y) = \sum_{n=1}^{\infty} b_n\,\frac{\sinh(n\pi y/a)}{\sinh(n\pi b/a)}\,\sin\frac{n\pi x}{a}, \]

and on the disc of radius \(R\) with boundary values \(f(\theta)\),

\[ u(r, \theta) = \frac{a_0}{2} + \sum_{n=1}^{\infty} \Bigl(\frac{r}{R}\Bigr)^n (a_n\cos n\theta + b_n\sin n\theta). \]

Both tails are geometric away from the boundary and are bounded the same way. At the centre of the disc only \(a_0/2\) survives: the value of a harmonic function at the centre of a circle is the mean of its values on the circle. For the disc, a point is given as \((r, s)\) with \(\theta = 2\pi s\), so that a rational \(s\) names an exact direction.

The wave equation

Every solution of \(u_{tt} = c^2 u_{xx}\) is a wave travelling right plus a wave travelling left. With \(u(x, 0) = f\) and \(u_t(x, 0) = g\), d'Alembert's formula is

\[ u(x, t) = \frac{f(x - ct) + f(x + ct)}{2} + \frac{1}{2c}\int_{x - ct}^{x + ct} g(s)\,ds . \]

On an interval with fixed ends the same formula holds once \(f\) and \(g\) are continued as odd functions of period \(2L\): the reflections at the ends are built in. wave uses this, so its values need no series and carry no truncation error. modes(N) lists the standing waves \(\sin(n\pi x/L)\cos(n\pi ct/L)\) with their certified amplitudes.

Sturm-Liouville problems

Separation of variables leads to eigenvalue problems \(-(p\,y')' + q\,y = \lambda\,w\,y\) with \(y(a) = y(b) = 0\). Solve from \(a\) with \(y(a) = 0\), \(y'(a) = 1\): the value \(y(b; \lambda)\) is a continuous function of \(\lambda\) that vanishes exactly at the eigenvalues. sturmLiouville finds the sign changes in floating point, then proves each: two validated solutions, at the ends of a small interval of \(\lambda\), have \(y(b)\) of opposite proven signs, so an eigenvalue lies between them.
