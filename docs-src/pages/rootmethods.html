Numerical methods

Root-finding methods

Bisection, fixed-point iteration, Newton's method and the secant method, each run in doubles the way a textbook runs it, with its table of iterations. Because the root is also known with certainty (from zeros), every row carries the true error, and the order of convergence is measured, not assumed.

const n = newton("x^2 - 2", 1);
n.iterations;   // [{ n, x, fx, dfx, error }, …]   error = |x − √2|, the real one
n.order;        // 1.9998   observed
n.root;         // the certified root the errors are measured against

bisection("x^2 - 2", [1, 2], { steps: 10 }).iterations;   // each with bound (b − a)/2ⁿ⁺¹ and the true error
secant("x^3 - x - 1", 1, 2).order;                         // about 1.6
fixedPoint("cos(x)", 1).multiplier;                        // g′ at the fixed point: −0.6736…

Order of convergence

With \(e_n = |x_n - x^*|\), a method has order \(p\) when \(e_{n+1} \approx C e_n^{\,p}\). Order 1 (with \(C < 1\)) gains a fixed number of digits each step; order 2 doubles the number of correct digits each step. From three successive errors,

\[ p \approx \frac{\log(e_{n+1}/e_n)}{\log(e_n/e_{n-1})}, \]

which is what order reports, using the last errors that are still well above rounding.

Why Newton's method squares the error

Expand \(f\) about \(x_n\) and evaluate at the root: \(0 = f(x_n) + f'(x_n)(x^* - x_n) + \tfrac12 f''(\xi)(x^* - x_n)^2\). Dividing by \(f'(x_n)\) and rearranging,

\[ x_{n+1} - x^* = \frac{f''(\xi)}{2 f'(x_n)}\,(x_n - x^*)^2 . \]

At a multiple root \(f'(x^*) = 0\), the argument fails, and the observed order drops to 1: try newton("(x - 1)^2", 2).

Fixed points and the multiplier

For \(x \leftarrow g(x)\), \(x_{n+1} - x^* = g(x_n) - g(x^*) \approx g'(x^*)(x_n - x^*)\). So each step multiplies the error by about \(g'(x^*)\). fixedPoint returns an enclosure of that multiplier at the certified fixed point and the observed ratio of successive errors, which should agree with it. The proof of convergence by the contraction principle is in recursive sequences.

What the true error shows

A program cannot know its error, so in practice the step size \(|x_{n+1} - x_n|\) or the residual \(|f(x_n)|\) stands in for it. Here the error itself is in the table, measured against a root enclosed to 25 digits, so the stand-ins can be judged. The last rows show the floor that rounding sets: the error stops near \(10^{-16}\) times the size of the root however many more steps are taken.
