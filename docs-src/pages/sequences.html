Sequences

A sequence is a formula in a whole number n, or a rule that makes each term from the one before. sequence and recursive give terms exactly, limits with a proof, and statements such as "decreasing from n = 3 on" that hold for every later term and not only the ones looked at.

const a = sequence("(1 + 1/n)^n");
a.terms(3);            // [2, 9/4, 64/27]   exact
a.limit();             // an interval of width 10^-20 around e
a.bounds();            // { lower, upper, bounded: true }: every term lies between them

const b = sequence("n/(n^2 + 10)");
b.monotone();          // { direction: "decreasing", from: 3, proven: "for every n ≥ 3" }
sequence("n^2/(n + 1)").limit();   // Infinity
sequence("2^n/n!").limit();        // 0, by the ratio of successive terms

Factorials are written n! or (2n)!. The index is n unless you pass { variable }, and starts at 1 unless you pass { from }.

What a limit means here

A sequence \(a_n\) has limit \(L\) when for every \(\varepsilon > 0\) there is an \(N\) with \(|a_n - L| < \varepsilon\) for all \(n \ge N\). Computing many terms can suggest a limit and cannot prove one: the definition is about all the terms that were not computed.

The library proves limits from the formula. On a ray \(x \ge X\) it writes the term as

\[ a(x) = e^{kx}\,x^{p}\,(\log x)^{m}\,\bigl(\ell + \rho(x)\bigr), \qquad |\rho(x)| \le \text{a bound that decreases to } 0, \]

with exact exponents and an interval for \(\ell\). The limit, or the fact that the sequence grows without bound, is read off the exponents, and the bound on \(\rho\) holds for every \(x \ge X\) at once. This is the same machinery as limits at infinity. Where it finds no such form, as for \(\sin n\), limit refuses.

Monotone and bounded

A sequence that is monotone and bounded converges; that theorem is how many limits are shown to exist before they are found. monotone() proves the direction by showing that the derivative of the formula has one sign on a ray \([N, \infty)\), then compares the terms before \(N\) one by one and moves \(N\) back as far as they agree. bounds() combines a bound valid on a ray with the finitely many terms before it.

If no proof is found the call refuses. For example the derivative of \((1 + 1/n)^n\) is a difference of two terms that nearly cancel, and its sign is not settled by this method, although its limit and bounds are.

Recursive sequences

const heron = recursive("x/2 + 1/x", { start: 2 });   // x₀ = 2, x_{k+1} = x_k/2 + 1/x_k
heron.terms(5);              // [2, 3/2, 17/12, 577/408, 665857/470832]
heron.fixedPoints([1, 2]);   // [{ point: [1.41421…], multiplier: [≈ 0], kind: "attracting", unique: true }]
heron.limit([1, 2]);         // { limit: [1.41421…], enters: 1, rate: 0.696…, basin: [0.914…, 1.914…] }

If \(x_{k+1} = g(x_k)\) converges and \(g\) is continuous, the limit is a fixed point, \(g(x^*) = x^*\). The multiplier \(g'(x^*)\) says what happens nearby: errors are multiplied by about \(g'(x^*)\) each step, so the fixed point attracts when \(|g'(x^*)| < 1\) and repels when \(|g'(x^*)| > 1\).

limit turns that into a proof by the contraction principle. It finds an interval \(I\) around a fixed point such that \(g(I) \subset I\) and \(|g'| \le q < 1\) on \(I\); then \(g\) has exactly one fixed point in \(I\) and every sequence that enters \(I\) converges to it, with \(|x_{k+1} - x^*| \le q\,|x_k - x^*|\). It then follows the sequence with interval arithmetic until a term is proven to lie in \(I\). The answer reports the step at which that happened and the rate \(q\).

Terms are exact fractions while they stay short (Heron's iteration doubles the number of digits each step) and certified intervals after that.
