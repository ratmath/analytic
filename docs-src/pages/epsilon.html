Topic

ε, N and δ, with certificates

The definitions of a limit and of continuity ask for a number: an \(N\) for each \(\varepsilon\), or a \(\delta\) for each \(\varepsilon\). nFor and deltaFor find one, say why it works for every later term or every nearby point, and hand back a certificate that verifyCertificate rechecks by a different route.

const a = sequence("(2n + 1)/(n + 3)");
const r = a.nFor("1/100");
r.N;        // 498, and r.least is true: 497 does not work
r.reason;   // "the terms rise to the limit for n ≥ 1, so |a(n) − L| never grows from there; …"
verifyCertificate(r.certificate).valid;   // true

const d = deltaFor("x^2", 2, "1/100");
d.delta;    // 249/100000, a δ that works
d.largest;  // [0.00249843…]: the largest one, √4.01 − 2
deltaFor("x^2", 2, "1/100", { delta: "0.003" }).holds;   // false

An N for ε

\(a_n \to L\) means: for every \(\varepsilon > 0\) there is an \(N\) with \(|a_n - L| < \varepsilon\) for all \(n \ge N\). Checking terms one at a time can never finish, so the statement about all \(n \ge N\) needs an argument. Two are used.

A monotone tail. If the terms are proven to rise (or fall) to \(L\) from some index on, then \(|a_n - L|\) never grows from there, and the first index where it is below \(\varepsilon\) is the answer. It is found by doubling and bisection, and it is the least \(N\): the term before it is checked to fail.

A dominating sequence. Otherwise, as for \(\sin(n)/n\), the asymptotic form of the sequences page gives a bound \(|a_n - L| \le C\,n^{p}(\log n)^m e^{kn}\) that decreases to 0. Past the index where the bound is below \(\varepsilon\) every term is within \(\varepsilon\); the finitely many terms before that are examined one by one, walking back to the last one that fails. If the walk reaches it, the \(N\) is again least.

Sequences with periodic factors, such as \((-1)^n/n^2\), are split into the subsequences \(n = pm + r\) first, and the answer is one past the last failing index over all of them.

A δ for ε

\(f\) is continuous at \(x_0\) when for every \(\varepsilon > 0\) there is a \(\delta > 0\) with \(|f(x) - f(x_0)| < \varepsilon\) whenever \(|x - x_0| \le \delta\). The quantity to control is

\[ \omega(\delta) = \sup_{|x - x_0| \le \delta} |f(x) - f(x_0)| . \]

Where \(f'\) is proven to keep one sign on each side of \(x_0\), the supremum is at an end of the interval and is computed exactly. Otherwise it is bounded by the certified range of \(f\) and by the mean value theorem, \(\omega(\delta) \le \delta\,\sup|f'|\), whichever is smaller. deltaFor halves \(\delta\) until \(\omega(\delta) < \varepsilon\).

The largest \(\delta\) is the distance from \(x_0\) to the nearest solution of \(f(x) = f(x_0) \pm \varepsilon\). Those are found with the certified zeros, which are complete on an interval: no solution is missed, so the nearest one really is nearest. For \(x^2\) at 2 with \(\varepsilon = 1/100\) it is \(\sqrt{4.01} - 2 \approx 0.0024984\), slightly less than the \(\varepsilon/4\) a first estimate suggests.

What the certificate is for

A certificate is a plain record of the claim: the formula, the point or limit, \(\varepsilon\), the number found and the argument used. verifyCertificate does not repeat the search. For an \(N\) it recomputes the limit, checks that the certificate's parts are the subsequences of this very sequence (one for each residue class when there is a factor such as \((-1)^n\)), proves the monotone direction again or compares the dominating bound with the terms at sampled indices and with \(\varepsilon\), finds the index where each tail argument takes over, and tests the inequality at every index from \(N\) up to there, one by one. Only then does it test the failure at \(N - 1\) when \(N\) is claimed least, and the inequality at a spread of later indices. So moving \(N\) before a bump in the terms is caught: for \(1/(1 + (n - 50)^2)\) and \(\varepsilon = \tfrac12\) the least \(N\) is 52, and a certificate edited to say \(N = 1\) fails at \(n = 49\). A monotone tail is proven; a dominating bound comes from the asymptotic form and the verifier only samples it against the terms, so for that method the replay is a strong check rather than a second proof. For a \(\delta\) it cuts the interval into cells and checks \(|f(x) - f(x_0)| < \varepsilon\) on each by plain interval evaluation, with no derivative and no root-finding. It returns the list of checks and whether all passed, so a wrong answer from either side shows up as a disagreement.
