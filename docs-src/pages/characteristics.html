First-order equations: characteristics

transport solves \(u_t + c\,u_x + k\,u = s\) with \(u(x, 0) = f(x)\) along characteristics: a closed formula where there is one, a certified value at a point otherwise, and a plain statement of where characteristics cross and the solution stops being a function.

const u = transport({ speed: 2, initial: "exp(-x^2)" });
u.formula;            // "exp(-(x - 2*t)^2)"
u.characteristics;    // "x - 2*t = const"
u.at(1, "1/2").value; // exactly 1: the foot of the characteristic is x = 0
u.residual(3, 1);     // [0, 0]: the formula put back into the equation

const b = transport({ speed: "u", initial: "exp(-x^2)", interval: [-4, 4] });
b.crossing.time;      // [1.165821…]: the breaking time sqrt(e/2)
b.at(1, 2);           // refuses: characteristics have crossed

The idea

Follow a curve \(x(t)\) with \(dx/dt = c\). Along it, by the chain rule, \(\frac{d}{dt}u(x(t), t) = u_t + c\,u_x\), so the partial differential equation becomes the ordinary one \(du/dt = s - k\,u\). With constant \(k\) and \(s\),

\[ u(x, t) = f(\xi)\,e^{-kt} + \frac{s}{k}\bigl(1 - e^{-kt}\bigr) \qquad (\,f(\xi) + s\,t \text{ when } k = 0\,), \]

where \(\xi\) is the foot: the point of the line \(t = 0\) from which the characteristic through \((x, t)\) started. Solving the equation is finding the foot.

  • Constant speed. The characteristics are the parallel lines \(x - ct = \xi\), and \(u = f(x - ct)\): the initial profile moves at speed \(c\) unchanged.
  • Speed \(ax + b\). \(dx/dt = ax + b\) gives \(\xi = (x + b/a)\,e^{-at} - b/a\), again a closed formula.
  • Any other \(c(x, t)\). The foot is the value at time 0 of the solution of \(dx/dt = c(x, t)\) through \((x, t)\), followed backwards by the validated ODE solver. The result is an enclosure of the foot, and so of \(u\).

In all three cases the characteristics are solutions of one ordinary differential equation, and two solutions through the same point are the same solution: they never cross, and \(u\) is defined for all time. Where there is a closed formula, residual(x, t) differentiates it and encloses \(u_t + c\,u_x + k\,u - s\) at a point, which is a check that does not go through characteristics at all.

When the speed depends on u

For \(u_t + c(u)\,u_x = 0\), such as Burgers' equation \(u_t + u\,u_x = 0\), \(u\) is still constant along each characteristic, so each one is a straight line whose slope is set by the value it carries:

\[ x = \xi + F(\xi)\,t, \qquad F(\xi) = c(f(\xi)). \]

Now the lines can meet. Two neighbours starting at \(\xi\) and \(\xi + d\xi\) cross when \(1 + F'(\xi)\,t = 0\), so the first crossing is at the breaking time

\[ t_b = \frac{-1}{\min_\xi F'(\xi)} \]

if \(F'\) is negative somewhere, and never if \(F' \ge 0\) (faster values ahead of slower ones: a rarefaction). Past \(t_b\) the method would assign several values to one point; the equation then has no classical solution, and at refuses instead of returning one of them.

With interval: [a, b] the least value of \(F'\) over starting points in \([a, b]\) is enclosed by subdivision, which gives an enclosure of \(t_b\) for those characteristics. Before the breaking time, \(\xi \mapsto \xi + F(\xi)\,t\) is increasing, so the foot is its one root, found by bisection. Without an interval the claim is local: at first proves \(1 + F'(\xi)\,t > 0\) on the bracket it found, and refuses where it cannot.
