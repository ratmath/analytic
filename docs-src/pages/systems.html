Systems in the plane

linearSystem solves \(x' = Ax\) exactly: for a 2 by 2 matrix it names the kind of equilibrium, and for larger matrices it gives \(e^{At}\) and the stability. planarSystem takes a nonlinear system, finds every equilibrium in a box with proof, and classifies each from its linearisation.

const s = linearSystem([[1, 2], [3, 2]]);
s.eigenvalues;      // ["-1", "4"]
s.kind;             // "saddle"
s.exponential;      // e^{At} as four formulas in t
s.solution([1, 0]); // ["2/5*exp(4*t) + 3/5*exp(-t)", "3/5*exp(4*t) - 3/5*exp(-t)"]

const pendulum = planarSystem(["y", "-sin(x) - y/2"], ["x", "y"]);
pendulum.equilibria({ x: [-4, 4], y: [-2, 2] });
// three records: saddle at (-π, 0), stable spiral at (0, 0), saddle at (π, 0)

Linear systems

With \(\tau = \operatorname{tr} A\) and \(\Delta = \det A\), the eigenvalues are \(\lambda = \tfrac12\bigl(\tau \pm \sqrt{\tau^2 - 4\Delta}\bigr)\), and the origin is

conditionkind
\(\Delta < 0\)saddle: real eigenvalues of opposite signs
\(\Delta > 0,\ \tau^2 > 4\Delta\)node: stable if \(\tau < 0\), unstable if \(\tau > 0\)
\(\Delta > 0,\ \tau^2 < 4\Delta,\ \tau \ne 0\)spiral: stable if \(\tau < 0\), unstable if \(\tau > 0\)
\(\Delta > 0,\ \tau = 0\)centre: closed orbits
\(\Delta > 0,\ \tau^2 = 4\Delta\)degenerate node, or a star when \(A\) is a multiple of the identity
\(\Delta = 0\)a line of equilibria

The entries are rational, so the signs of \(\tau\), \(\Delta\) and \(\tau^2 - 4\Delta\) are decided exactly and the borderline cases are recognised for what they are.

The solution is \(x(t) = e^{At}x(0)\). For a 2 by 2 matrix, with \(\mu = \tau/2\) and \(\delta = \mu^2 - \Delta\),

\[ e^{At} = e^{\mu t}\Bigl(c(t)\,I + s(t)\,(A - \mu I)\Bigr), \qquad (c, s) = \begin{cases} (\cosh\omega t,\ \sinh(\omega t)/\omega) & \delta = \omega^2 > 0 \\ (1,\ t) & \delta = 0 \\ (\cos\omega t,\ \sin(\omega t)/\omega) & \delta = -\omega^2 < 0, \end{cases} \]

which follows from \((A - \mu I)^2 = \delta I\) (Cayley-Hamilton).

Larger systems

For an \(n\) by \(n\) matrix, \(e^{At}\) is the inverse Laplace transform of \((sI - A)^{-1}\), because \(\mathcal{L}\{e^{At}\} = (sI - A)^{-1}\). The Faddeev–LeVerrier recursion gives this inverse with exact rational coefficients: with \(M_1 = I\),

\[ M_{k} = A M_{k-1} + c_{n-k+1} I, \qquad c_{n-k} = -\tfrac1k \operatorname{tr}(A M_k), \qquad (sI - A)^{-1} = \frac{\sum_{k=1}^{n} M_k\, s^{\,n-k}}{p(s)}, \]

where \(p(s) = s^n + c_{n-1}s^{n-1} + \dots + c_0\) is the characteristic polynomial. Each entry is then inverted by partial fractions. This works when \(p\) splits over the rationals into linear factors and quadratics. The result is checked: \(\tfrac{d}{dt}e^{At} = A\,e^{At}\) identically and \(e^{A\cdot 0} = I\), and verified reports it.

const s3 = linearSystem([[0, 1, 0], [0, 0, 1], [-6, -11, -6]]);
s3.characteristic;   // "s^3 + 6*s^2 + 11*s + 6 = 0"
s3.eigenvalues;      // ["-1", "-2", "-3"]
s3.stability;        // "asymptotically stable"
s3.solution([1, 0, 0])[0];   // "3*exp(-t) - 3*exp(-2*t) + exp(-3*t)"
linearSystem([[0, 1, 0], [0, 0, 1], [0, 0, 0]]).exponential[0];   // ["1", "t", "1/2*t^2"]

Stability is read from the real parts of the eigenvalues, whose signs are decided exactly. If every real part is negative, the system is asymptotically stable; if any is positive, it is unstable. Eigenvalues on the imaginary axis give stability that is not asymptotic, if each is semisimple, which is checked exactly by a rank. Otherwise the system is unstable: a repeated zero eigenvalue with a Jordan block makes \(e^{At}\) grow like a power of \(t\). For other matrices, use the matrix exponential in the linear algebra package.

Nonlinear systems

An equilibrium of \(x' = f(x, y),\ y' = g(x, y)\) is a common zero of \(f\) and \(g\). equilibria(box) bisects the box, discards pieces where interval arithmetic shows \(f\) or \(g\) has no zero, and applies a Krawczyk test to the rest: when the test succeeds there is exactly one equilibrium in that piece. The returned list has complete: true when every part of the box was either proven empty or proven to hold exactly one equilibrium.

Near an equilibrium the system looks like its linearisation, \(x' = Jx\) with \(J\) the Jacobian matrix there. If no eigenvalue of \(J\) has zero real part (the equilibrium is hyperbolic), the nonlinear system has the same kind of equilibrium with the same stability (Hartman-Grobman). The trace and determinant of \(J\) are enclosed over the small box that holds the equilibrium, so a reported saddle, node or spiral is proven. When the linear part is a centre, the nonlinear terms decide, and the record says so.

Two tools settle such cases. conserves(H) checks that \(H_x f + H_y g\) is identically zero: a conserved quantity with a strict extremum at the equilibrium makes it a centre. along(V) gives \(\dot V = V_x f + V_y g\) for a candidate Lyapunov function.
