First-order equations: the methods

The validated solver answers "what is y(2)?" with a proof and no formula. A course asks for the formula and for the method that finds it. firstOrder recognises the standard types of equation \(y' = f(x, y)\), carries out the method, and reports every step. exactEquation does the same for \(M\,dx + N\,dy = 0\).

const s = firstOrder("x - 2*y");          // y' = x - 2y
s.type;       // "linear"
s.general;    // "y = 1/2*x - 1/4 + C*exp(-2*x)"
s.steps;      // [{ what, formula }, …]

const p = s.through(0, 1);                // the solution with y(0) = 1
p.solution;   // "1/2*x - 1/4 + 5/4*exp(-2*x)"
p.check(1);   // { agree: true, numeric: […], formula: […] }

A formula that has been checked

Every closed form here can be compared with the validated numerical solution. check(x1) solves the initial value problem to \(x_1\) with proven error bounds and evaluates the formula there with proven error bounds; the two enclosures of \(y(x_1)\) must meet. For a solution given only as a relation \(G(x, y) = C\), the relation is evaluated on the numerical enclosure and must contain the constant. A wrong formula fails this test, so a mistake in the algebra cannot pass unnoticed. A check takes from a fraction of a second to some seconds, depending on the equation.

The types

typeformmethod
linear\(y' = a(x) + b(x)\,y\)multiply by \(\mu = e^{-\int b\,dx}\); then \((\mu y)' = \mu a\)
separable\(y' = g(x)\,h(y)\)\(\int dy/h(y) = \int g(x)\,dx + C\)
Bernoulli\(y' = p(x)\,y + q(x)\,y^n\)\(v = y^{1-n}\) makes it linear
homogeneous\(y' = F(y/x)\)\(y = vx\) makes it separable: \(x v' = F(v) - v\)
exact\(M\,dx + N\,dy = 0\) with \(M_y = N_x\)find \(\varphi\) with \(\varphi_x = M\), \(\varphi_y = N\); solutions are \(\varphi = C\)

An equation can be of several types: \(y' = xy\) is linear and separable. types lists all that apply and type is the one used; pass { method } to choose. A linear equation is solved as linear because that gives \(y\) outright. A separable equation gives a relation between \(x\) and \(y\), reported as implicit, and where the relation is easily solved (a logarithm, a reciprocal, an arctangent) also as general.

Dividing by \(h(y)\) loses the constant solutions \(y = y_0\) with \(h(y_0) = 0\). They are listed in singular.

Why the integrating factor works

For \(y' - b\,y = a\), multiply by \(\mu(x)\). The left side becomes \(\mu y' - \mu b\,y\), which is the derivative of the product \(\mu y\) exactly when \(\mu' = -\mu b\), that is \(\mu = e^{-\int b}\). Then \((\mu y)' = \mu a\) is solved by one integration:

\[ y = \frac{1}{\mu}\Bigl(\int \mu\,a\,dx + C\Bigr). \]

Exact equations

If \(\varphi(x, y)\) is constant along a solution then \(\varphi_x\,dx + \varphi_y\,dy = 0\). So \(M\,dx + N\,dy = 0\) is solved at once if \(M = \varphi_x\) and \(N = \varphi_y\) for some \(\varphi\), and since mixed partials agree that requires \(M_y = N_x\). When the test fails, a factor \(\mu\) may repair it: if \((M_y - N_x)/N\) depends on \(x\) alone then \(\mu(x) = e^{\int (M_y - N_x)/N\,dx}\) works, and likewise with the roles exchanged. exactEquation tries both.

const e = exactEquation("3*x*y + y^2", "x^2 + x*y");
e.exact;       // false
e.factor;      // "x"
e.potential;   // "y*x^3 + 1/2*y^2*x^2"     solutions: that = C

The integrals

The methods need antiderivatives. antiderivative(tree, name) covers polynomials, rational functions by partial fractions, exponentials and sines of linear arguments with polynomial factors, and one level of substitution; it returns nothing unless differentiating its answer gives the integrand back. When an integral is not found, type is null and the validated solver is still there. The fuller engine is in the symbolic package.
