Numerical methods

Differences and quadrature rules

The classical formulas for derivatives and integrals, with the true error of each beside the textbook estimate: difference quotients and the step size at which rounding takes over, Richardson extrapolation, the composite midpoint, trapezoid and Simpson rules, Romberg's table, and Gauss-Legendre rules with certified nodes and weights.

const d = differences("exp(x)", 1, { kind: "central" });
d.rows;    // [{ h, value, error, truncation }, …]  for h = 1e-1 … 1e-12
d.best;    // the h with the smallest true error

quadratureRule("exp(x)", [0, 1], { rule: "simpson", n: 4 });
// { value, exact, error, bound, order: 4 }

gaussLegendre(3);   // { polynomial: "5/2*x^3 - 3/2*x", nodes, weights }  enclosures

Difference quotients

kindformulatruncation error
forward\(\dfrac{f(x + h) - f(x)}{h}\)\(\tfrac12 f''(x)\,h\)
central\(\dfrac{f(x + h) - f(x - h)}{2h}\)\(\tfrac16 f^{(3)}(x)\,h^2\)
second\(\dfrac{f(x + h) - 2f(x) + f(x - h)}{h^2}\)\(\tfrac1{12} f^{(4)}(x)\,h^2\)

The truncation error shrinks with \(h\). The rounding error grows: the numerator is a difference of nearly equal numbers, accurate to about \(\varepsilon|f|\) with \(\varepsilon \approx 10^{-16}\), and dividing by \(h\) makes that \(\varepsilon|f|/h\). The total is smallest near \(h \approx \sqrt\varepsilon\) for the forward difference and \(h \approx \varepsilon^{1/3}\) for the central one. differences evaluates the quotient in doubles for a range of \(h\) and reports the true error of each against the certified derivative, so the turn is visible in the table, with the predicted truncation term beside it.

Richardson extrapolation

The central difference has an error expansion in even powers, \(D(h) = f'(x) + c_2h^2 + c_4h^4 + \dots\). Then \(\bigl(4D(h/2) - D(h)\bigr)/3\) cancels the \(h^2\) term, and repeating the idea cancels \(h^4\), \(h^6\), and so on. richardson builds the triangular table; romberg does the same for the trapezoid rule, whose error has the same kind of expansion (Euler-Maclaurin).

quadratureRule evaluates the rule with certified arithmetic, so error is the error of the method alone, with no rounding mixed in. exact is the certified integral and bound the textbook bound with the maximum of the derivative enclosed. The true error is always inside the bound, and usually well inside.

Darboux sums

The lower and upper Darboux sums of a partition use the inf and the sup of \(f\) on each piece, \(L = \sum m_i\,\Delta x_i\) and \(U = \sum M_i\,\Delta x_i\), and every integral lies between them. darboux(f, partition) takes a list of points or { interval, n }. On a piece where \(f'\) is proven to have one sign, \(f\) is monotone and its inf and sup are its end values, so for a polynomial or rational function the sums are exact fractions: for \(x^2\) on \([0, 1]\) with four pieces, \(L = \tfrac{7}{32}\) and \(U = \tfrac{15}{32}\). Where monotonicity is not proven, the inf and sup come from the end values and the certified critical points inside, the sums are intervals that contain the true sums, and exact is false.

Gauss rules

With \(n\) points chosen freely, a rule can be exact for all polynomials of degree below \(2n\). The points are the roots of the Legendre polynomial \(P_n\), and the weights are \(w_i = 2/\bigl((1 - x_i^2)\,P_n'(x_i)^2\bigr)\). gaussLegendre(n) builds \(P_n\) with exact coefficients, isolates its roots with proof, and returns nodes and weights as enclosures to 25 digits.
