Systems in the plane

linearSystem solves x′=Axx' = Axx′=Ax exactly: for a 2 by 2 matrix it names the kind of equilibrium, and for larger matrices it gives eAte^{At}eAt and the stability. planarSystem takes a nonlinear system, finds every equilibrium in a box with proof, and classifies each from its linearisation.

const s = linearSystem([[1, 2], [3, 2]]);
s.eigenvalues;      // ["-1", "4"]
s.kind;             // "saddle"
s.exponential;      // e^{At} as four formulas in t
s.solution([1, 0]); // ["2/5*exp(4*t) + 3/5*exp(-t)", "3/5*exp(4*t) - 3/5*exp(-t)"]

const pendulum = planarSystem(["y", "-sin(x) - y/2"], ["x", "y"]);
pendulum.equilibria({ x: [-4, 4], y: [-2, 2] });
// three records: saddle at (-π, 0), stable spiral at (0, 0), saddle at (π, 0)

const s3 = linearSystem([[0, 1, 0], [0, 0, 1], [-6, -11, -6]]);
s3.characteristic;   // "s^3 + 6*s^2 + 11*s + 6 = 0"
s3.eigenvalues;      // ["-1", "-2", "-3"]
s3.stability;        // "asymptotically stable"
s3.solution([1, 0, 0])[0];   // "3*exp(-t) - 3*exp(-2*t) + exp(-3*t)"
linearSystem([[0, 1, 0], [0, 0, 1], [0, 0, 0]]).exponential[0];   // ["1", "t", "1/2*t^2"]

Stability is read from the real parts of the eigenvalues, whose signs are decided exactly. If every real part is negative, the system is asymptotically stable; if any is positive, it is unstable. Eigenvalues on the imaginary axis give stability that is not asymptotic, if each is semisimple, which is checked exactly by a rank. Otherwise the system is unstable: a repeated zero eigenvalue with a Jordan block makes eAte^{At}eAt grow like a power of ttt. For other matrices, use the matrix exponential in the linear algebra package.

Nonlinear systems

An equilibrium of x′=f(x,y), y′=g(x,y)x' = f(x, y),\ y' = g(x, y)x′=f(x,y), y′=g(x,y) is a common zero of fff and ggg. equilibria(box) bisects the box, discards pieces where interval arithmetic shows fff or ggg has no zero, and applies a Krawczyk test to the rest: when the test succeeds there is exactly one equilibrium in that piece. The returned list has complete: true when every part of the box was either proven empty or proven to hold exactly one equilibrium.

Near an equilibrium the system looks like its linearisation, x′=Jxx' = Jxx′=Jx with JJJ the Jacobian matrix there. If no eigenvalue of JJJ has zero real part (the equilibrium is hyperbolic), the nonlinear system has the same kind of equilibrium with the same stability (Hartman-Grobman). The trace and determinant of JJJ are enclosed over the small box that holds the equilibrium, so a reported saddle, node or spiral is proven. When the linear part is a centre, the nonlinear terms decide, and the record says so.

Two tools settle such cases. conserves(H) checks that Hxf+HygH_x f + H_y gHx​f+Hy​g is identically zero: a conserved quantity with a strict extremum at the equilibrium makes it a centre. along(V) gives V˙=Vxf+Vyg\dot V = V_x f + V_y gV˙=Vx​f+Vy​g for a candidate Lyapunov function.
