First-order equations: characteristics

transport solves ut+c ux+k u=su_t + c\,u_x + k\,u = sut​+cux​+ku=s with u(x,0)=f(x)u(x, 0) = f(x)u(x,0)=f(x) along characteristics: a closed formula where there is one, a certified value at a point otherwise, and a plain statement of where characteristics cross and the solution stops being a function.

const u = transport({ speed: 2, initial: "exp(-x^2)" });
u.formula;            // "exp(-(x - 2*t)^2)"
u.characteristics;    // "x - 2*t = const"
u.at(1, "1/2").value; // exactly 1: the foot of the characteristic is x = 0
u.residual(3, 1);     // [0, 0]: the formula put back into the equation

const b = transport({ speed: "u", initial: "exp(-x^2)", interval: [-4, 4] });
b.crossing.time;      // [1.165821…]: the breaking time sqrt(e/2)
b.at(1, 2);           // refuses: characteristics have crossed
