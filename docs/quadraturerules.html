Numerical methods

Differences and quadrature rules

The classical formulas for derivatives and integrals, with the true error of each beside the textbook estimate: difference quotients and the step size at which rounding takes over, Richardson extrapolation, the composite midpoint, trapezoid and Simpson rules, Romberg's table, and Gauss-Legendre rules with certified nodes and weights.

const d = differences("exp(x)", 1, { kind: "central" });
d.rows;    // [{ h, value, error, truncation }, …]  for h = 1e-1 … 1e-12
d.best;    // the h with the smallest true error

quadratureRule("exp(x)", [0, 1], { rule: "simpson", n: 4 });
// { value, exact, error, bound, order: 4 }

gaussLegendre(3);   // { polynomial: "5/2*x^3 - 3/2*x", nodes, weights }  enclosures

Richardson extrapolation

The central difference has an error expansion in even powers, D(h)=f′(x)+c2h2+c4h4+…D(h) = f'(x) + c_2h^2 + c_4h^4 + \dotsD(h)=f′(x)+c2​h2+c4​h4+…. Then (4D(h/2)−D(h))/3\bigl(4D(h/2) - D(h)\bigr)/3(4D(h/2)−D(h))/3 cancels the h2h^2h2 term, and repeating the idea cancels h4h^4h4, h6h^6h6, and so on. richardson builds the triangular table; romberg does the same for the trapezoid rule, whose error has the same kind of expansion (Euler-Maclaurin).

quadratureRule evaluates the rule with certified arithmetic, so error is the error of the method alone, with no rounding mixed in. exact is the certified integral and bound the textbook bound with the maximum of the derivative enclosed. The true error is always inside the bound, and usually well inside.

Gauss rules

With nnn points chosen freely, a rule can be exact for all polynomials of degree below 2n2n2n. The points are the roots of the Legendre polynomial PnP_nPn​, and the weights are wi=2/((1−xi2) Pn′(xi)2)w_i = 2/\bigl((1 - x_i^2)\,P_n'(x_i)^2\bigr)wi​=2/((1−xi2​)Pn′​(xi​)2). gaussLegendre(n) builds PnP_nPn​ with exact coefficients, isolates its roots with proof, and returns nodes and weights as enclosures to 25 digits.
