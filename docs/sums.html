Series and convergence tests

sum(term) is the series ∑an\sum a_n∑an​. Each convergence test of a calculus course is a method that returns its verdict together with the quantity that decided it, and sum() encloses the value of a convergent series: finitely many terms, plus an interval proven to hold all the rest.

const s = sum("1/n^2");
s.convergence();   // { convergence: "absolutely convergent", by: "comparison", reason: "|a(n)| behaves like 1·n^-2, …" }
s.partial(3);      // 49/36   exact
s.sum();           // { enclosure: [1.6449340656…, 1.6449340674…], terms: 512, tail: […], by: "integral bounds for a convex term: …", met: true }

sum("n/2^n").ratioTest();      // { test: "ratio", verdict: "convergent", limit: 1/2, reason: … }
sum("(-1)^n/n").convergence(); // conditionally convergent, by the alternating series test
sum("1/n").sum();              // refuses: the series diverges (comparison test: …)

The tests

Every test returns { test, verdict, reason, … } with verdict "convergent", "divergent" or "inconclusive". Inconclusive is a real answer: the ratio test says nothing about ∑1/n2\sum 1/n^2∑1/n2, and the method says so.

tests() runs all six, and convergence() picks the conclusion: absolutely convergent, conditionally convergent (the alternating test passes and the series of sizes is proven to diverge), divergent or undecided.

The limits in these tests are proven, not estimated. The term is first read as an=(±1)n qn⋅(factorials)⋅r(n)a_n = (\pm1)^n\, q^n \cdot (\text{factorials}) \cdot r(n)an​=(±1)nqn⋅(factorials)⋅r(n). In the ratio an+1/ana_{n+1}/a_nan+1​/an​ the power leaves the constant qqq and each factorial leaves a polynomial, exactly as when the ratio is simplified by hand, and what is left is handled by the asymptotic form of rrr.

The sum, with a proven tail

Write S=SN+RNS = S_N + R_NS=SN​+RN​ with SNS_NSN​ the sum of the terms up to NNN and RNR_NRN​ the tail. SNS_NSN​ is computed exactly or enclosed. For RNR_NRN​ one of these bounds is proven, and the result names it in by:

  • Ratio. If ∣an+1∣≤ρ ∣an∣|a_{n+1}| \le \rho\,|a_n|∣an+1​∣≤ρ∣an​∣ for all n≥Nn \ge Nn≥N with ρ<1\rho < 1ρ<1, then ∣RN∣≤∣aN+1∣/(1−ρ)|R_N| \le |a_{N+1}|/(1-\rho)∣RN​∣≤∣aN+1​∣/(1−ρ). The bound on the ratio is proven on the whole ray [N,∞)[N, \infty)[N,∞).
  • Integral. For a positive decreasing term, ∫N+1∞a≤RN≤∫N∞a\int_{N+1}^\infty a \le R_N \le \int_N^\infty a∫N+1∞​a≤RN​≤∫N∞​a. If the term is also convex, comparing the curve with trapezoids and with midpoint rectangles gives the much tighter ∫N∞a dx−aN2  ≤  RN  ≤  ∫N+12∞a dx. \int_N^\infty a\,dx - \frac{a_N}{2} \;\le\; R_N \;\le\; \int_{N+\frac12}^\infty a\,dx . ∫N∞​adx−2aN​​≤RN​≤∫N+21​∞​adx. The improper integrals are the certified ones from Limits and improper integrals.
  • Alternating. The tail lies between 0 and its first term. If the sizes are convex as well, it lies between aN+1/2a_{N+1}/2aN+1​/2 and −aN/2-a_N/2−aN​/2, which gains several digits for slowly convergent series such as ∑(−1)n/n\sum (-1)^n/n∑(−1)n/n.
  • Comparison. If only a bound ∣an∣≤C np(log⁡n)m|a_n| \le C\,n^p(\log n)^m∣an​∣≤Cnp(logn)m is known (as for sin⁡n/n2\sin n / n^2sinn/n2), the tail is at most the integral of the bound.

NNN is doubled until the enclosure is as narrow as digits asks (default 8) or maxTerms is reached; met says which. Whatever the width, the enclosure contains the sum.
