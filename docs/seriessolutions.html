Series solutions

Many equations of physics have no solution in elementary functions: Airy's, Bessel's, Legendre's. Their solutions are defined by power series. seriesSolution builds those series for y′′+p(x) y′+q(x) y=0y'' + p(x)\,y' + q(x)\,y = 0y′′+p(x)y′+q(x)y=0 about a point, with exact rational coefficients, and says what kind of point it is.

seriesSolution({ q: "-x", order: 7 });            // Airy: y'' = x y
// kind "ordinary", solutions "1 + 1/6*x^3 + 1/180*x^6 + …" and "x + 1/12*x^4 + 1/504*x^7 + …"

seriesSolution({ p: "1/x", q: "(x^2 - 1/4)/x^2" });   // Bessel of order 1/2
// kind "regular singular", indicial "r^2 - 1/4 = 0", exponents [1/2, -1/2], two series

Regular singular points and Frobenius

If ppp has at most a simple pole and qqq at most a double pole at x0x_0x0​, the point is a regular singular point. Write xp(x)=∑Pkxkx p(x) = \sum P_k x^kxp(x)=∑Pk​xk and x2q(x)=∑Qkxkx^2 q(x) = \sum Q_k x^kx2q(x)=∑Qk​xk (taking x0=0x_0 = 0x0​=0). The larger root always gives a series. The smaller root gives a second one unless the roots are equal or differ by a whole number, in which case the bracket on the left can vanish for some nnn; then the second solution contains log⁡x\log xlogx, and notes says so. (When the right side happens to vanish too, the series exists after all, as for Bessel's equation of order one half.)

A point where the poles are worse is an irregular singular point, and the method does not apply.

A proven remainder

for any ρ\rhoρ below provenRadius. enclose(x) evaluates the partial sum at a rational point and puts that bound on either side.

const cos = seriesSolution({ q: "1", order: 12 }).solutions[0];   // y'' + y = 0, y(0) = 1, y'(0) = 0
cos.remainder(1).bound;        // 447/1000000000000: the terms beyond x^12 are below 4.47e-10 on the unit disc
const e = cos.enclose("1/2");  // { partial, bound, low, high }
e.low.toDecimal(15), e.high.toDecimal(15);   // both 0.877582561890372…: cos(1/2) to 13 places, proven

Checking a series

The coefficients are exact, and a partial sum is a polynomial whose value at a rational point is an exact rational. Comparing it with the validated solution of the same initial value problem shows the true truncation error next to the proven bound, as in the box below.
