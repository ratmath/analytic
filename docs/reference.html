Reference

Everything in the library

Numbers can be JS integers, bigints, strings such as "3/4" or "0.1" (decimals are exact), Core Rationals, or Core intervals such as R`1/2:1`. Functions marked R return a Refinement: .quick is the float preview, .exact() or await .settle() gives the certified answer. When a hypothesis fails (a log of something that can reach 0, a divisor that can be 0, a point outside the domain), the library throws an AnalyticError with a code and a reason. It does not return a bound it cannot prove.

Grammar: + - * / ^ (or **), parentheses, implicit products (2x, 3(x+1), 2sin(x)), -x^2 = -(x^2), ^ right-associative. Functions: exp log ln log1p sqrt cbrt sin cos tan asin acos atan sinh cosh tanh erf erfc abs min max (arcsin arccos arctan too), and the special functions gamma lgamma digamma trigamma beta(a, b) besselJ(n, x) Si fresnelS fresnelC; constants pi e. A power with an odd denominator, x^(1/3), is the real root and is defined for negative x. Ranges and integrals may cross points where the function is not smooth (abs, cbrt at 0); there the bounds come from interval evaluation. It is the same grammar and the same plain AST as @ratmath/graphics.

Options: variable, params, tolerance (bracket width, default 10⁻⁶), pieces (starting pieces, 16), maxDepth (48), maxMultiplicity, flatBits, maxBoxes (2000 per piece), maxMs (8000 in all), sliceMs (15). Previews are { kind: "guess", at }. A stretch of the interval with no record certainly holds none.

kind or fieldmeaning
exactf(at) = 0 exactly, at a rational point
everywhere, constantthe function is identically zero (for zeros) or constant (for extrema) on [lo, hi]; one record covers the stretch
sign-changef has opposite proven signs at lo and hi; with unique, exactly one zero inside
isolatedexactly one zero inside, but f keeps its sign (found through sqrt, abs or an even power)
possibleundecided: maybe no zero, maybe several; atMost: m bounds the count with multiplicity
undefinedf is not defined somewhere on the bracket
boundproven max |f| on a possible bracket of a flat function
budgetthe bracket was left when the work budget ran out
touchingf′ (or f″) has the same proven sign at both ends: no feature, or a pair of them inside

Errors

Every refusal is an AnalyticError with a code. The common ones:

codewhen
domainlog, sqrt or a power is applied outside its domain (log of a range that reaches 0)
division-by-zeroa divisor's range contains 0
not-smoothabs, min or max at a corner inside the domain
overflowexp of an argument above 2¹⁶, or a value too large to enclose
hypothesisa series rule fails on the checked terms
outside-domaina model or ODE solution asked about a point outside where it is valid
unbounda name in a formula has no value
bad-expression, bad-region, bad-piecewise, bad-ode, bad-seriesinput that does not parse or does not make sense
budgeta series or search ran past its limit
